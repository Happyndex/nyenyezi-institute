## Publish for free with GitHub Pages
1. Create or sign in to a free account at https://github.com/
2. Create a new **public** repository, for example `nyenyezi-institute`.
3. Upload `index.html` and the `assets` folder (keep the folder structure).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide a public address similar to `https://YOUR-USERNAME.github.io/nyenyezi-institute/`.

The GitHub Pages address is free; it is a platform subdomain, not a custom `.com` domain.
A public site can be indexed by search engines, but appearing in search results is not guaranteed or immediate. After publishing, submit the site URL in Google Search Console to request indexing.
